# Backend

API y servidor en tiempo real del juego de dominó (NestJS + Socket.IO).

- `src/game/domino.ts`: motor del juego (reglas puras, sin dependencias).
- `src/game/rooms.service.ts`: salas, jugadores y vista de cada jugador.
- `src/game/game.gateway.ts`: eventos de Socket.IO.

Ver el README principal para instrucciones.
